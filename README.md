# Devine Neuf

Jeu de soirée ciné et séries sur un seul téléphone. Une équipe lit la question et coche les réponses. L'autre équipe cherche les 9 réponses.

Jouer : https://alexla92.github.io/devine-neuf/

Les questions viennent de la banque de questions dans Notion. Le jeu tient dans `index.html`.
